What runs, what doesn’t

The measurement half is real. The order path is held shut.

Runs today

  • Ingest: Weave, JSON, OTLP, Claude Code
  • Metadata-only allowlist
  • Daily dollar and token ledger
  • Paper hedge sizing
  • Contract discovery and order construction, dry run
  • Backtest, paper settlement, scorecard
  • CME compute futures: sizing only, needs a broker

Not yet

  • Basis: not measured, needs a real ledger
  • Order path: built, never armed
  • Live orders: zero placed
  • Forward pricing: in progress
  • Compute perpetuals: not listed
  • Model routing and content storage: not built
